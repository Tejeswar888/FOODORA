## Features
- Home page and navigation
- Food menu and categories
- Food search
- Food item cards
- Add items to bag
- Increase and decrease quantities
- Remove items
- Order summary
- Our Story page
- Contact page
- Responsive design

## How to Use the Website
1. Open the FOODORA website.
2. Navigate to the Menu section.
3. Browse food items.
4. Add items to the bag.
5. Update quantities.
6. Review the order summary.
7. Explore the ordering interface.

## Running the Project Locally

### Requirements
- Node.js
- npm
- Visual Studio Code

### Installation
```bash
git clone https://github.com/Tejeswar888/FOODORA.git
cd FOODORA
npm install
npm run dev
```

Use the start command specified in package.json if the project does not use Vite.
